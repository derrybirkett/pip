# Reflection Pattern

**Pattern Type**: Agent Workflow  
**Primary Users**: All agents  
**Purpose**: Turn completed work into reusable learning by reviewing outcomes, misses, and next
steps.

## Overview

Use Reflection after execution, releases, audits, or incidents. The goal is to improve the next
decision, not to relitigate the previous one.

## Reflection Questions

1. What happened?
2. What worked well?
3. What did not work or surprised us?
4. Which assumptions were wrong?
5. What should change in the process, docs, or tooling?

## Good Outputs

- Short retrospective notes
- Updated runbooks or patterns
- New guardrails, tests, or validation
- Follow-up tasks with clear ownership
