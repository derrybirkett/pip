# Multi-Agent Collaboration Pattern

**Pattern Type**: Agent Workflow  
**Primary Users**: CEO, CTO, CPO, CISO, CMO, CRO, COO  
**Purpose**: Coordinate work across agents with clear decision rights, handoffs, and escalation
paths.

## Overview

Use this pattern when a task crosses product, technical, security, operations, or commercial
boundaries. Collaboration works best when every agent knows what they own and what they are waiting
for.

## Core Rules

1. Name the decision owner.
2. State the input each collaborating agent needs.
3. Share concise status and reasoning at handoff points.
4. Escalate disagreements to the right decision-maker quickly.
5. Capture the final decision in durable docs.

## Typical Handovers

- CPO to CTO for implementation
- CTO to CISO for security review
- CTO and CMO for technical launch messaging
- COO coordinating release readiness across functions
